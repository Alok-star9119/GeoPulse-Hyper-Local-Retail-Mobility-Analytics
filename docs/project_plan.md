# GeoPulse - Project Plan

## Problem Statement
Retailers lack hyper-local visibility into how people move around their stores.
GeoPulse analyses mobility data to reveal footfall patterns, peak hours,
catchment areas and location performance.

## Key Questions
1. When and where is foot traffic highest around each store?
2. Which neighbourhoods drive the most visits (catchment analysis)?
3. How do weather, weekday/weekend and events affect mobility?
4. Which store locations are under/over-performing, and why?

## Deliverables
- Cleaned, validated datasets
- EDA notebooks and geospatial maps
- Interactive dashboard (Streamlit)
- Final report with actionable recommendations
- Documentation (data dictionary, progress log)
